# Tech Salary Analysis

This is a Data Science project that analyzes global technology salary data using Python and Jupyter Notebook.

## Project Overview

This project focuses on understanding salary trends in the technology industry.

The analysis explores how factors such as job title, remote work ratio, company size, experience level, and work year affect salaries. The goal is to provide useful insights that can support HR consulting and compensation decisions.

## Business Background

In a competitive technology job market, companies need to offer competitive salary packages to attract and retain top talent.

This analysis helps identify salary trends across different roles, remote work arrangements, and company sizes.

## Objectives

- Explore the salary dataset
- Check dataset information and missing values
- Identify the top 5 job titles with the highest average salary in USD
- Compare average salaries by remote work ratio
- Analyze salary distribution across company sizes
- Analyze average salary by experience level
- Identify the most common job titles
- Analyze salary trends by work year
- Create visualizations
- Extract useful insights

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Insights

- Some job titles have significantly higher average salaries than others.
- Remote work ratio shows differences in average salary levels.
- Medium-sized companies show a wide salary distribution and many high salary outliers.
- Experience level has a clear impact on average salary.
- Some job titles appear more frequently in the dataset than others.
- Average salaries changed across different work years.
- Salary insights can help companies make better compensation decisions and stay competitive in hiring.
